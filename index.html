Cómo usar MegaFlow

1. Preparar facturas

  1. Arrastra el PDF de órdenes Coral (o pulsa Seleccionar PDF). Puedes cargar un PDF con todas las órdenes, varios PDF individuales o agregarlos por partes.
  2. Revisa la fecha de factura, la condición de pago y el vencimiento.
  3. Pulsa Analizar pedidos. Si todo es correcto, descarga el Excel Odoo y el Excel de control.
  4. En Odoo: Contabilidad → Clientes → Facturas → ⚙ Importar registros → carga el Excel → Probar → Importar. Las facturas quedan en borrador.

2. Armar expedientes

  1. Carga órdenes, facturas y prevalidaciones en sus tres áreas (en cualquier orden y cantidad de archivos).
  2. Pulsa Analizar y relacionar documentos. La prevalidación une cada pedido (PEDIDO) con su factura (REFERENCIA).
  3. Si la tabla no muestra errores, pulsa Generar PDF final y luego Descargar PDF completo.

Privacidad

Los documentos se leen únicamente en la memoria de este navegador. No se envían a GitHub ni a ningún servidor, y no se guardan: al cerrar o recargar la página desaparecen. La página aplica una política de seguridad que bloquea conexiones a otros sitios. Solo se guarda tu preferencia de tema claro/oscuro.

Problemas frecuentes

  • "Parece escaneado": el PDF es una imagen sin texto. Usa el PDF digital original.
  • "Parece una factura, no una orden": el archivo está en el área equivocada.
  • "Producto desconocido" o "precio diferente": revisa la orden o actualiza el catálogo en js/config.js.
  • Si algo no responde, abre Diagnóstico (pie de página) y copia el detalle para soporte.
